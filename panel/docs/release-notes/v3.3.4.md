# v3.3.4
<!-- release-title: 仪表板秒开；支持 Server酱³；Alpine 上 Playwright 报错给出出路；修复退出或撤销登录后旧凭证仍能用 -->

## 新功能

- Server酱 渠道支持 Server酱³ 的 SendKey（`sctp` 开头）。Server酱³ 的 App 走手机厂商的系统推送，不开 App 也能收到，iOS 也能用。

## 优化

- 仪表板、侧栏角标、执行日志列表大幅提速（#153）：日志多的面板打开仪表板，不再卡十几秒甚至超时报错。
- Alpine 镜像里脚本因为 Playwright 失败时，任务日志和失败通知会直接说明原因和出路（#154）：把镜像标签里的 latest 换成 debian，再到「依赖管理 → Linux」点「安装 Playwright 运行环境」。
- 执行日志的实时输出在登录被撤销后会自动断开。

## 修复

- 退出登录、撤销会话、修改或重置密码、修改角色、禁用或删除用户之后，其它设备上续期过的登录仍能继续使用。现在会立即失效；升级不会让已登录的网页和 APP 掉线。
- 「撤销其他会话」有时会把自己也撤掉。
- 自动安装依赖的日志粘成一行；任务配了失败重试时，安装失败会被误报成「已安装但仍然报错」。

## 注意

- 升级后第一次启动会为执行日志建立索引，日志多的面板要多等几秒到几十秒，只有这一次。
- 删除用户、用命令行重置密码或用户名之后，该用户的所有登录都会失效。
- 建议升级后到「系统设置 → 账号安全 → 会话管理」看一遍，撤销不认识的会话。
- 手工粘贴在 MCP 客户端或脚本里的登录令牌，升级后可能需要重新获取；长期集成请改用「开放 API」里的应用令牌。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 在面板内一键更新。
