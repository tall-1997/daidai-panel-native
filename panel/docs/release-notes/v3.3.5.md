# v3.3.5
<!-- release-title: 标签栏可点选已有标签；容器重建后启动快很多；停容器、重启面板时先收尾再退出 -->

## 新功能

- 任务的标签栏会列出已有标签，点一下就加上，打字可以搜索（#157）；「批量添加标签」和「任务分组」也能直接点选已有的。
- 开放 API 新增 `GET /api/tasks/labels`，MCP 新增只读工具 `list_task_labels`。

## 优化

- 容器重建、重启后启动快很多（#156）：启动时检查已装依赖改为每个 Python 版本只查一次，依赖越多省得越多。
- 停容器、重启面板、在线升级时，面板会先收尾再退出：运行中的任务记为「面板正在关闭，任务已中断」，不再出现「面板上次异常退出」。
- 改了任务分组后，顶栏的分组页签立即更新；视图管理里那个开关改名「顶栏分组页签」，有没保存的改动时关闭会先确认。
- 启动时不再把脚本目录里的 `__pycache__`、`node_modules` 挪进隔离区。

## 修复

- 在标签栏输入后没按回车直接保存，标签不会存上（#157）。
- 视图管理的设置没保存成功时仍提示「已保存」，刷新后又变回去。
- 带版本号的 Python 依赖（如 `requests==2.31`）每次重启都被当成缺失重装一遍。
- 依赖安装日志偶尔缺几行，或末尾多出一行「读取安装输出失败」。
- 修改任务时写入失败，界面仍提示更新成功。
- 用 `ddp sub pull` 拉取会自动添加任务的订阅时，命令行会崩溃。

## 注意

- 停容器或重启面板时被打断的任务不再执行后置脚本，也不发失败通知；手动停止任务的行为不变。
- 带版本号或 extras 的 Python 依赖，重启后只检查包在不在，不再强制装回固定的版本。
- 之前被挪进 `quarantine/scripts/` 的 `__pycache__.duplicate-*`、`node_modules.duplicate-*` 不会自动删除，可以手动清理。
- 开放 API 更新任务时，`name`、`command` 或常规定时任务的 `cron_expression` 传 `null` 现在返回 400。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 在面板内一键更新。
