# v3.3.2
<!-- release-title: 主题跟随系统；企业微信拉起任务；清理日志连文件一起删；依赖镜像源换默认 -->

## 新功能

- 面板主题新增「跟随系统」（#145）：跟着操作系统的浅色 / 深色自动切换，在「个人设置 → 界面主题」里选。
- 企业微信应用可以拉起面板里已配置的任务（#145）：支持发指令和点菜单链接两种方式，在「系统设置 → 企业微信」里配置。
- 定时任务可以单独设置日志保留天数（#144）：在任务的「高级设置」里，不填就跟随全局。每分钟跑一次的任务可以单独设短一点。

## 优化

- 移动端（#144）：
  - 操作菜单里的「启用」常态就是绿色。
  - 弹窗铺满屏幕，顶栏不再占着上面一条。
  - 执行日志的「查看」弹窗改为全屏。
  - 脚本管理页的刷新按钮、搜索栏、编辑器工具栏，圆角、尺寸和间距统一。
  - 任务卡片右上角的「···」不再偏右。
  - 视图栏、状态栏、批量栏改回左右留白，屏幕边缘让给系统的侧滑返回；两条灰底栏也加了圆角。
  - 订阅管理、执行日志的卡片，字号和间距与定时任务卡片对齐。
  - 仪表板卡片圆角加大。
- 依赖镜像源默认改为腾讯云，另外新增华为云、天翼云（#146）。阿里云仍在列表里，可以手动选回。
- 安装 Playwright 时会提示下载体量和预计耗时；arm64 设备的浏览器下载走国内镜像。
- 两处「清理日志」的默认天数统一成全局设置里的值。

## 修复

- 清理日志只清掉了记录，`logs/` 下的日志文件还留着（#144）。现在自动清理、两处手动清理、删除日志、删除任务都会把对应文件一并删掉。
- 电脑端「日志文件」窗口出现三条滚动条，窗口矮时要先滚外层才能看到里面的滚动条（#144）。
- 切换 apt 源之后装系统包报 `E: Unable to locate package`（#146）：换源后会自动刷新软件包索引。
- 只改 pip 源、不动 Linux 源时，点保存报错（#146）。

## 注意

- **清理日志与删除任务现在会连磁盘上的日志文件一起删，删掉就找不回来了。** 正在执行的任务日志会被跳过，下一轮清理再收。
- 默认镜像源从阿里云换成腾讯云。一直用默认源的面板会在下次装包时自动切过去；手动选过源的保持不变。
- 系统处于深色模式的用户，升级后面板会跟着变暗，可以在「个人设置 → 界面主题」改回明亮。
- 企业微信拉起任务需要面板能被公网访问，并在企业微信后台填好回调地址与可信 IP。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 在面板内一键更新。
