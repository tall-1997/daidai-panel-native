# v3.2.9
<!-- release-title: 订阅不再给没写 cron 的脚本建 0 点任务；通知支持 HTML 与按渠道发送；脚本树自动定位 -->

## 新功能

- 通知 helper 支持内容格式与按渠道发送（#135）：`notify.send(标题, 正文, content_type="html")` 时邮件收到 HTML，不支持 HTML 的渠道自动转成纯文本；新增 `send_to()` 与 `wxpusher_bot`、`smtp` 等青龙同名函数，`sendNotify.js` 新增 `sendTo()`。用法见 [脚本 API](https://github.com/linzixuanzz/daidai-panel/blob/main/docs/script-api.md)。
- 打开脚本时，左侧目录树自动展开并定位到该文件（#136）。

## 优化

- 新建/编辑订阅弹窗精简：说明改成字段旁的「?」，不常用的设置收进「高级设置」。
- 系统设置「面板外观」更名「通用设置」并改为左右两栏；「依赖安装超时」「检测脚本半路静默结束」移到「任务运行」，「界面圆角」移到「面板外观」。
- 系统设置概览去掉「系统更新设置」卡片，静默更新开关与上次检查时间在「代理设置」。
- 订阅能识别更多 cron 写法：带引号、文件带 BOM、写在前 120 行内。

## 修复

- 订阅里没写 cron 的脚本被建成每天 0 点运行的任务（#134）。
- 设置页配置没加载成功时点保存，会把未显示的配置写回默认值。

## 注意

- 订阅里没写 cron 的脚本不再自动建任务，拉取日志会列出这些脚本；需要的话在「订阅设置 → 默认 Cron 规则」填一个规则。
- 之前按 0 点建出来的任务不会被自动删改：不需要的手动删除即可，删了不会再重建；脚本其实写了 cron 却一直是 0 点的，删掉任务后重新拉取会按脚本里的 cron 重建。
- `POST /api/v1/notifications/send` 新增 `content_type`、`channel_type(s)`、`channel_name(s)`，传了无效值会返回 400（以前会被忽略）；通知 helper 里的同名参数不再作为模板变量。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 在面板内一键更新。
