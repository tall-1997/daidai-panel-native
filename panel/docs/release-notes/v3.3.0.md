# v3.3.0
<!-- release-title: Node 升级到 24；MCP 对齐开放 API；修复 CPU 使用率读数偏高 -->

## 新功能

- MCP 新增 23 个工具，补齐开放 API 的能力（#139）：任务新建与修改、脚本删除 / 重命名 / 移动 / 复制 / 批量删除、执行代码片段、脚本历史版本与回滚、订阅增删改与启停、环境变量批量操作与导入导出、发送通知、备份创建 / 删除 / 恢复。写入类工具仍只在开启写权限时可用。
- MCP 读取脚本支持分段读取，大文件不再被静默截断（#139）。
- `/system/info` 返回面板版本号；`run-code` 接受 `bash` 作为语言（#139）。

## 优化

- Node.js 统一升级到 24 LTS：Magisk 模块、Docker 镜像、一键安装的 Node 运行时。
- Magisk Alpine 版基础系统升级到 Alpine 3.23，Python 随之升到 3.12。
- 升级后已装依赖自动迁移：Python 依赖按新版本自动重装，加载失败的 Node 原生扩展自动重建。
- 开放 API 文档写清 MCP 与 REST 两种鉴权的区别（#139）。

## 修复

- CPU 使用率读数偏高，两核机器常显示 50% 左右（#140）。

## 注意

- Magisk 用户需要重新刷入模块 ZIP 才能用上 Node 24 / Python 3.12，面板内一键更新只更新面板本身。
- Docker Debian 镜像不再提供 `linux/arm/v7`（Node 24 官方镜像没有该平台），32 位设备请改用 `latest` / `latest-full`。
- MCP 的 `read_script` 不再返回 `content_truncated`，改用 `truncated` 与 `next_offset` 表示是否读完。

## 升级

Docker 重新拉取镜像；Magisk 重新刷入模块 ZIP；裸机与 Windows 在面板内一键更新。
