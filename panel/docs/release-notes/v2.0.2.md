# v2.0.2

## 更新内容

### 安全

- 订阅、Git、通知出站收紧到允许的地址，并拒绝选项注入和私网目标。
- 备份、脚本和压缩包路径限制在各自目录内，下载文件名不能拆开 HTTP 头。
- 密钥和本机 token 改为常量时间比较；查看 OpenAPI Secret 必须验证当前管理员密码。
- 角色权限与面板合同对齐：终端、脚本、订阅至少 operator；备份至少 admin。
- 应用内检查更新读取本仓库已发布版本，不再查询其他仓库。

### 依赖

- `websocket-client` 安装成功后按模块 `websocket` 验证，不再因为 `websocket_client` 不存在而中止脚本。

### 安装包

- ARM64：`daidai-panel-native-2.0.2-prerelease-arm64.apk`
- x86_64：`daidai-panel-native-2.0.2-prerelease-x86_64.apk`

本版本为预发行，请只从本仓库 Release 安装。
