# v3.3.6
<!-- release-title: 任务结束后清理残留进程，内存不再越跑越高；执行趋势保留历史；环境变量可标为「重要」 -->

## 新功能

- 环境变量可以标为「重要」（APP #16）：名称旁显示紫色锁标识，删除时单独确认，批量删除会跳过重要变量；导出、导入、备份都会带上这个标记。
- 执行趋势和「今日 / 昨日执行」不再随日志清理变少（#158）：删除日志前会先把条数按天记下来。
- 「系统设置 → 任务运行」新增「任务结束后清理残留进程」开关，默认开启。

## 优化

- 任务结束后会清理脚本留在后台的进程，容器内存不再越跑越高（#159）；开机任务不清理。
- 停止任务或任务超时时，先通知脚本收尾，5 秒后仍未退出再强制结束，浏览器类脚本不再残留浏览器进程。
- 脚本「调试运行」「运行代码」的记录会自动清理，不再一直占用内存。
- 面板日志不再整份读进内存；设置页只在打开「面板日志」时自动刷新。
- 启动更快：依赖校验少起几个子进程，扫描脚本目录改在后台进行。

## 修复

- 导入环境变量时，已禁用的变量被导成启用。
- 网页删除环境变量失败时没有任何提示。
- 环境变量同时置顶又标为重要时，变量名在窄屏上几乎看不见。

## 注意

- 在定时或手动任务里用 `nohup … &` 拉起的常驻进程，任务结束时会被一并结束：需要常驻请改用 `setsid nohup … &`、放进开机任务，或在系统设置里关闭「任务结束后清理残留进程」。
- 执行趋势从本版本起累计，升级前已经清理掉的日志补不回来。
- 停止任务时，脚本最多有 5 秒收尾时间。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 在面板内一键更新。
