## 新功能

- 内置 MCP 服务（#128）：AI 客户端可通过 HTTP 或 `ddp mcp` 连接面板，查询任务、日志、脚本、环境变量等。默认关闭；运行任务、修改变量、写脚本这类操作需另外开启。用法见 [MCP 说明](https://github.com/linzixuanzz/daidai-panel/blob/main/docs/mcp.md)。
- 订阅的白名单、黑名单、依赖规则支持正则（#129），如 `^jd[^_]`；普通写法不受影响。
- 敏感环境变量默认遮蔽（#127），每行可单独查看，也可切换为全部明文。
- 编辑环境变量时可填写排序值（#131）。
- 任务页顶栏显示 App 里建的分组（#130）。
- 个人设置新增「界面动效」：系统开了「减少动态效果」时，可选择仍然播放动画（#132）。

## 优化

- 切页、弹窗、下拉、菜单加上过渡动画，下拉浮层改为毛玻璃；执行趋势图鼠标滑动不再掉帧（#132）。
- 编辑器在空闲时预加载，首次打开不再长时间白屏；静态资源开启压缩与长缓存（#133）。
- 日志自动跟随最新输出：往上翻时暂停，回到底部恢复，去掉「跟随」开关（#133）。
- 任务状态与按钮配色调整；订阅页的启用开关与状态圆点改成与环境变量页一致（#133）。

## 修复

- 禁用的任务手动运行时，操作菜单显示成「禁用」；运行期间编辑后可能被重新启用（#133）。
- 环境变量后置顶的反而排在前面；置顶项拖不到置顶区末尾，分页时拖到页底会跑到最后一页（#131）。
- 升级后浏览器沿用旧缓存，导致样式缺失、编辑器加载失败（#126）。
- 排队中的任务打开日志，显示的是上一次运行的结果。
- 订阅填了「指定子目录」时，子目录外的依赖文件会被建成定时任务（#129）。
- 点停止后任务可能仍在重试；停在重试等待里时要等满间隔才生效；任务刚开始运行时点停止可能停不掉，还会挡住下一次运行。
- 面板关闭或重启时，刚启动的任务可能留下无人管的进程继续运行。

## 注意

- 升级后如果界面看起来没变，按 Ctrl+F5 强制刷新一次；之后再升级，页面会自动刷新（有未保存的脚本或配置时改为提示）。
- 新置顶的环境变量排在已置顶的后面。同名多账号变量按列表顺序拼接，调整顺序会改变账号顺序。
- 订阅白名单、黑名单里原本就写了正则的片段，升级后会按正则生效；开着「自动删除失效任务」时，没命中或被排除的脚本对应的任务会被删除。含 `^ $ ( ) [ ] { } ? \` 的片段按正则解析，想当普通字符用请加 `\` 转义，路径分隔请写 `/`。
- 订阅填了「指定子目录」时，之前多建出来的子目录外任务会在下次拉取时被排除；开着「自动删除失效任务」的会一并删掉，脚本文件不受影响。
- 接口变化：任务列表新增 `enabled` 字段；新增 `GET /api/v1/tasks/groups`、`POST /api/v1/mcp`；`PUT /api/v1/envs/sort` 与 `PUT /api/v1/envs/:id` 支持 `position`。
