# v3.4.0
<!-- release-title: 任务可以限定能用的环境变量，变量页分组筛选可搜索 -->

## 新功能

- 定时任务新增「环境变量」设置：可选「全部」或「指定」分组 / 变量名。指定后只把这些变量交给脚本，脚本里的面板令牌也只能用来发通知（#168）。APP v1.4.4 起也能设置。
- 环境变量页的「分组筛选」可以打字搜索（#167）。

## 注意

- 「指定」能减少脚本拿到不相关的变量，但不是沙箱：脚本仍能通过 ddp 命令或直接读取面板数据拿到全部变量，来路不明的脚本不要运行。
- 现有任务默认是「全部」，升级后行为不变。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 在面板内一键更新。
