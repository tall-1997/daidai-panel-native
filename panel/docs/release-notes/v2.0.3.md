# v2.0.3

## 更新内容

### 通知

- 脚本通知不再把登录 token 当作本机校验头。本机校验只使用单独的本机 token，失败响应也不再回显 token。

### 依赖

- 取消正在安装或卸载的依赖时会终止对应进程。系统包安装同样可以取消。

### 任务

- cron 的 `5/10` 这类「起点/步长」按标准从起点步进到字段上限。

### 安装包

- ARM64：`daidai-panel-native-2.0.3-stable-arm64.apk`
- x86_64：`daidai-panel-native-2.0.3-stable-x86_64.apk`

本版本为正式版。已通过 x86_64 模拟器运行时验证。ARM64 真机验证仍缺少自托管 runner。请只从本仓库 Release 安装。
