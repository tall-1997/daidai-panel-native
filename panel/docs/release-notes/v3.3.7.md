# v3.3.7
<!-- release-title: 脚本管理可直接查看图片、支持排序；导入环境变量不再因备注相同被合并；Docker 可指定监听地址 -->

## 新功能

- 脚本管理里点开图片文件（png / jpg / gif / webp / bmp / ico）可直接预览，点击放大。
- 脚本列表可按名称、创建时间或修改时间排序（#160）；按名称排序时数字按大小、中文按拼音。
- Docker 新增环境变量 `PANEL_HOST`，可指定监听地址（#162）：例如 host 网络下设为 `127.0.0.1`，只允许本机访问，再由外层 Nginx 反代。

## 修复

- 导入环境变量时，备注相同的变量被合并成一条（#161）：新增「按名称 + 值合并」并设为默认，原来的「按名称 + 备注合并」仍可选；导入结果分别显示新建和更新的数量。

## 注意

- 设置 `PANEL_HOST` 后，容器内的后端端口 5701 也只在本机监听；填写的不是有效 IP 时容器会启动失败并提示原因。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 在面板内一键更新。
