# v3.3.9
<!-- release-title: pip 可设官方源，httpx[http2] 这类带 extras 的依赖能正常安装 -->

## 修复

- 依赖管理把 pip 源设成官方源（pypi.org）后，保存时会被换回默认的腾讯云（#165）。npm 官方源同样修好，快捷选择里新增「PyPI 官方」「npm 官方」。
- 脚本提示 `pip install httpx[http2]` 时，自动安装只装了 httpx，h2 仍然缺失（#166）。
- 已装 httpx 后在依赖管理里再装 `httpx[http2]`，会被当成「已存在」跳过（#166）。现在会补装 extras，原来锁定的版本号会保留。
- 新建依赖时，`httpx[http2,socks]` 方括号里的逗号不再被当成分隔符。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 在面板内一键更新。
