# v3.3.3
<!-- release-title: 批量设置任务通知；按定时时刻排序；修复 iOS 弹窗被顶栏遮挡与 Python 依赖卸载不干净 -->

## 新功能

- 定时任务可以批量设置通知（#149）：选中任务或「全部任务」，一次开启 / 关闭失败、成功、终止通知。入口在「⋯」菜单，移动端在批量栏和「+」菜单。
- 任务列表可以按定时规则的每天执行时刻排序（#151）：在排序菜单里选，或点「定时规则」表头，00:00 → 23:59 排列，方便看每个时间段有哪些任务。
- 打开已结束的任务日志时可以直接定位到底部（#147）：在「个人设置 → 日志查看」里开启，跟随账户，换设备、APP 里都生效。默认仍停在开头。
- 从 latest（Alpine）镜像换到 debian 镜像后，面板启动时会自动重装不兼容的 Python 原生扩展（#150）。

## 优化

- 依赖「导出清单」按安装时填写的原样导出（#150）：当初写了版本号的才带，可以直接粘贴回「新建依赖」。
- 天翼云镜像源去掉「实验性」标记（#150）。
- 企业微信应用渠道的「反代基础地址」改名为「反代基础地址 / 微信代理」，wxchat 等微信代理填在这里（#152）。
- 企业微信拉起任务的使用说明写清哪些需要公网可达。
- 青龙备份导入时带上企业微信的 `QYWX_ORIGIN`。

## 修复

- iOS Safari 上弹窗顶部被导航栏遮挡（#148）。
- iOS Safari 上打开弹窗后滑动，偶尔滚动的是背后的页面；点输入框时页面会自动放大（#148）。
- 强制卸载、批量卸载 Python 依赖时实际没有删除文件（#150）。

## 注意

- 导出清单不再附带已安装的版本号。
- 视图里原有的「按定时规则」排序改为按每天的执行时刻，顺序会和之前不同；手动、开机任务排在最后。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 在面板内一键更新。
