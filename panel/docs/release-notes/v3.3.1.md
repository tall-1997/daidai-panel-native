# v3.3.1
<!-- release-title: 移动端页面重新布局；Playwright 运行环境一键安装，容器重建后自动恢复 -->

## 新功能

- 依赖管理 → Linux 新增「安装 Playwright 运行环境」（#142）：一键装好 Chromium 需要的系统库、Python 的 playwright 和浏览器。浏览器放在数据目录，容器重建后系统库会在后台自动重装。仅支持 Debian 版 Docker 镜像。
- 定时任务、环境变量的每页条数，以及视图栏「全部 / 分组」的显示设置，改为跟随账户，换浏览器、换域名或 IP 都会保留（#143）。

## 优化

- 移动端页面重新布局（#143）：
  - 工具栏精简为一行，按钮只留图标；勾选后整行切换成批量操作栏，新增「全选」。
  - 卡片只保留关键信息，字段名和值排在同一行；常用按钮放在右下角，其余操作收进右上角「···」。
  - 视图栏、状态栏可以左右滑动，并贴满屏幕宽度。
  - 侧边栏改为半屏宽；「界面圆角」选「圆角」时，卡片和按钮更圆。
  - 弹窗的关闭按钮移到右下角。
- 翻页后自动回到列表顶部。
- 定时任务操作菜单里的「启用」，悬停时显示为绿色。
- 任务因缺少 Playwright 浏览器或系统库失败时，日志里会给出处理办法。

## 修复

- iPhone Safari 上顶栏盖住弹窗，右上角的关闭按钮点不到（#143）。
- 容器重建后 Playwright 找不到浏览器（#142）。
- 容器重建后自动重装 Linux 依赖时没有使用镜像源，而且可能和手动安装争抢 apt 锁而失败。
- 移动端翻页后，上一页勾选的项目仍然生效。

## 注意

- 之前手动装过 Playwright 的用户，升级后在「依赖管理 → Linux」点一次「安装 Playwright 运行环境」即可，以后容器重建不需要再手动修复。
- 移动端不再显示任务的命令、定时规则和标签；环境变量的导入、多格式导出，以及状态和分组筛选，只在电脑端提供。
- `PUT /api/v1/auth/preferences` 新增 `list` 组；请求体里一组都不带时，不再写入默认值。

## 升级

Docker 重新拉取镜像；Magisk、裸机与 Windows 在面板内一键更新。
