# v2.0.1

## 更新内容

### 本地面板

- Git 仓库订阅支持面板里保存的 SSH 私钥，拉取使用一次性临时钥和 `GIT_SSH_COMMAND`。
- 订阅可按 cron 自动刷新，也可手动 refresh；停止拉取会杀掉正在跑的 git 进程。
- 恢复备份时进度条会显示当前阶段和百分比，不再只有 0% / 100%。
- 脚本运行会发放 2 小时短时 token，跑完即作废，避免长期本机 token 留在环境变量里。
- TypeScript 优先走 ts-node / tsc；格式化找不到 black、gofmt、shfmt 时会明确提示。
- 设置页检查更新会查询 GitHub Release；赞助页在源站不可用时给出 unavailable 状态。

### 登录与任务

- 两步验证只在服务端明确要求 TOTP 时弹出，不再把普通 4xx 当成验证码挑战。
- 任务 cron 解析结果会展示下次执行时间。

### 安装包

- ARM64：`daidai-panel-native-2.0.1-prerelease-arm64.apk`
- x86_64：`daidai-panel-native-2.0.1-prerelease-x86_64.apk`

本版本为预发行通道，ARM64 真机证据仍为 pending。
