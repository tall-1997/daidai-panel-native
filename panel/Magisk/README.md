# Magisk 目录说明

本目录不是本仓库的发行物。

[tall-1997/daidai-panel-native](https://github.com/tall-1997/daidai-panel-native) 只发布非 Root Android 本机版 APK。这里不提供 Magisk、KernelSU 或 APatch 模块，也不提供其他仓库的模块下载、更新地址或安装步骤。

请从本仓库 Release 下载：

- ARM64：`daidai-panel-native-2.0.2-prerelease-arm64.apk`
- x86_64：`daidai-panel-native-2.0.2-prerelease-x86_64.apk`

安装包和更新说明以仓库根目录 README 为准。
