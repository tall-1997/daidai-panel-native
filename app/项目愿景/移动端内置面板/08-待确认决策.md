# 待确认决策

## 产品决策

1. “全部功能”的官方定义采用管理功能完整、执行功能分级。
2. Android 普通版是否要求无常驻通知运行长期 Cron。
3. Root Android 版是否作为独立安装包、独立渠道或 App 内增强模式。
4. iOS 是否接受混合执行作为完整脚本能力的正式方案。
5. 本地面板是否默认只允许当前设备访问。

## 技术决策

1. Android MVP 采用 Go Mobile 库或受管本地服务。
2. 上游后端代码采用 Git Submodule、构建期拉取或独立共享模块。
3. Python 与 Node 运行时随 App 首包提供，或首次启用时按需下载。
4. Git 使用 libgit2、JGit 或受控命令行实现。
5. 执行节点协议基于现有 Open API 扩展，或新增专用双向协议。
6. 本地 API 使用动态回环端口，或迁移为进程内 Repository。

## 分发决策

1. Android 是否通过 GitHub APK、应用商店或双渠道发布。
2. 大体积运行时是否使用 Play Asset Delivery 或独立签名组件仓库。
3. iOS App Store 审核基线和允许的脚本编辑、远程执行产品文案。
4. Root 组件的免责声明、支持范围和升级责任。

## 建议默认值

- Android 首发架构：ARM64。
- Android 默认运行时：Python 3.12、Node.js 20 LTS、TypeScript 固定稳定版。
- Android 本地服务：仅回环地址。
- Android 调度：用户启用持续运行后使用前台服务。
- iOS：本地管理核心加远程完整执行。
- 数据：默认 App 私有目录，用户主动导出加密备份。
- 运行时：按需下载、签名校验、版本锁定和空间配额。
