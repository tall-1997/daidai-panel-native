# 功能兼容矩阵

## 等级定义

- A：可实现与后端面板一致的主要行为。
- B：可实现核心行为，受后台、运行时或系统 API 限制。
- C：采用远程执行或系统替代方案。
- D：公开分发环境下缺少可靠实现路径。

## 管理功能

| 功能 | Android 普通 | Android Root | iOS 沙箱 | 实现说明 |
|---|---:|---:|---:|---|
| 管理员初始化与登录 | A | A | A | 本地核心与安全存储 |
| Dashboard | A | A | A | 资源指标调整为 App 与沙箱维度 |
| 任务 CRUD | A | A | A | 共享数据库与 API |
| Cron 配置 | A | A | A | 执行保障等级按平台展示 |
| 日志与 SSE | A | A | A | 本地或进程内事件流 |
| 环境变量 | A | A | A | 敏感值使用平台密钥保护 |
| 脚本文件管理 | A | A | A | App 私有目录与文件导入导出 |
| 订阅管理 | B | A | B | Git 能力和后台同步受平台影响 |
| 通知渠道 | A | A | A | 网络通知渠道可复用 |
| 依赖管理 | B | A | C | 原生扩展兼容性是主要差异 |
| 用户与角色 | A | A | A | 本地单机仍保留多用户能力 |
| 2FA 与会话 | A | A | A | 可复用现有契约 |
| IP 白名单 | B | A | B | 回环服务场景意义降低 |
| 数据备份恢复 | A | A | A | 使用系统文件选择器导入导出 |
| Open API | B | A | B | 本地服务后台可用性决定外部访问 |
| 系统健康诊断 | A | A | A | 按平台提供不同检查项 |
| 本地自更新 | A | A | C | iOS 通过 App Store 更新 |

## 执行功能

| 运行能力 | Android 普通 | Android Root | iOS 沙箱 | 说明 |
|---|---:|---:|---:|---|
| Python 脚本 | B | A | C | Android 需内嵌 ABI 运行时；iOS 主线走远程节点 |
| Node.js 脚本 | B | A | C | Android 使用内嵌 Node；iOS 主线走远程节点 |
| Shell 脚本 | B | A | D | 普通 Android 为受控命令集 |
| TypeScript | B | A | C | 通过内嵌编译器或远程节点 |
| Go 脚本 | C | A | C | 本地即时编译体积与工具链成本高 |
| pip 纯 Python 包 | B | A | C | Android 可安装纯 Python 包 |
| pip 原生扩展 | C | B | C | 需要预编译 ABI 包或远程执行 |
| npm 纯 JS 包 | B | A | C | 内嵌 Node 环境可覆盖 |
| npm 原生模块 | C | B | C | 需要 Android ABI 构建 |
| Git HTTPS 订阅 | B | A | B | 可内嵌 libgit2 或精简 Git |
| Git SSH 订阅 | B | A | B | 需要密钥与 known_hosts 管理 |
| 长期精确 Cron | B | A | D | Android 普通版依赖前台服务 |
| 手动执行 | A | A | B | iOS 限于允许的本地动作 |
| 任务停止与超时 | A | A | B | 进程或执行节点控制 |

## 后端特有功能处理

| 功能 | 移动端策略 |
|---|---|
| Docker 更新 | 替换为 App 与内置核心协同更新 |
| Linux 包管理 | Root Android 提供；普通 Android 使用运行时组件仓库 |
| Android Runtime 管理 | 本地 Android 版转换为自身运行时中心 |
| Nginx 配置 | 本地核心直接提供 API；无需独立 Nginx |
| 主机 CPU 与磁盘指标 | 展示移动设备与 App 沙箱指标 |
| 开机启动 | Root Android 可完整支持；普通 Android 遵循系统后台策略 |

## “全部功能”验收口径

项目文案应将“全部功能”拆为两个声明：

1. 管理功能完整：三个平台均以覆盖后端业务管理模块为目标。
2. 执行功能分级：Root Android 提供完整本地执行；普通 Android 提供主流受控运行时；iOS 通过混合执行覆盖完整任务类型。
