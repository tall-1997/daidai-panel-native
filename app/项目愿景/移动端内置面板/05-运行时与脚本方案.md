# 运行时与脚本方案

## 目标

用户安装 App 后即可执行常用任务。运行时由 App 管理版本、校验、磁盘占用、依赖目录和升级，用户无需安装独立 Python、Node.js、Git 或 Docker。

## Android 普通版

### Python

建议发行独立 ABI 运行时组件：

- `arm64-v8a` 作为首发架构。
- Python 3.12 作为默认版本。
- 标准库、pip 和证书包随运行时提供。
- 每个 Python 小版本使用独立依赖目录。
- 纯 Python wheel 可在线安装。
- 原生扩展通过经过签名的预编译 wheel 仓库提供。

### Node.js

- 内嵌 Android 对应 ABI 的 Node.js 运行时。
- npm 缓存和项目依赖存放在 App 私有目录。
- 支持纯 JavaScript 包。
- 原生 addon 通过预编译组件仓库提供。

### Shell

- 内嵌受控 BusyBox 或 Toybox 工具集。
- 工作目录限定在 App 数据目录和用户授权目录。
- 命令能力通过白名单和能力声明管理。
- 网络、存储和高资源操作在任务创建时提示权限与风险。

### TypeScript

- 通过内嵌 Node.js 与固定版本 TypeScript 编译器执行。
- 编译缓存按源码摘要管理。
- 任务日志区分编译阶段和运行阶段。

### Go

推荐首期采用远程执行节点。完整 Go 工具链体积较大，移动端即时编译还涉及模块缓存、交叉编译和存储压力。后续可支持预编译二进制任务或受信任的 WASM 任务。

### Git

优先使用 libgit2 或受控 Git 实现完成：

- HTTPS clone、fetch 和 checkout。
- SSH Key、Token 和 known_hosts。
- 白名单路径检出。
- 订阅更新的原子替换与回滚。

## Android Root 版

复用上游 Magisk 方案：

- Linux 根文件系统。
- Python、Node.js、Git 和包管理器。
- Go 后端二进制。
- 开机启动与长期运行。

App 负责模块安装引导、状态检测、日志展示、端口配置和升级。模块负责系统级运行环境。

## iOS 沙箱版

公开分发主线采用以下能力：

- 数据管理和脚本编辑保留在本地。
- 受控内置动作可在前台执行。
- 完整 Python、Node.js、Shell、TypeScript 和 Go 任务发送到远程执行节点。
- App 接收实时日志、停止任务和持久化结果。

可研究 WebAssembly 执行受控任务，适用于纯计算、明确导入接口和资源限制场景。WASM 不能直接替代通用 Shell、pip、npm 或系统命令环境。

## 运行时组件模型

每个组件包含：

```json
{
  "id": "python-3.12-android-arm64",
  "version": "3.12.x",
  "platform": "android",
  "architecture": "arm64-v8a",
  "size": 0,
  "sha256": "<SHA256>",
  "capabilities": ["python", "pip", "venv"]
}
```

运行时管理器负责：

- 签名与 SHA-256 校验。
- 临时目录解压和原子切换。
- 旧版本清理。
- 磁盘配额。
- 任务运行期间引用计数。
- 失败回滚。

## 资源控制

- 每个任务配置超时、并发、输出上限和工作目录。
- 日志流设置内存缓冲上限并持续落盘。
- 子进程退出时回收进程树和临时文件。
- 依赖缓存、运行时和日志分别设置配额。
- 低电量、过热和低存储时暂停低优先级任务。
