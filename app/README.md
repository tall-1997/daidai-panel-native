# 呆呆面板 Android 客户端

本目录是 [呆呆面板本机版](https://github.com/tall-1997/daidai-panel-native) 的 Flutter 客户端，当前版本 **v2.0.2**。

它负责 Android 上的本机面板界面，也可以连接远程面板。安装包、更新说明和仓库介绍以仓库根目录 [README.md](../README.md) 与 [CHANGELOG.md](../CHANGELOG.md) 为准。

本目录不单独发布安装包，也不使用其他仓库的版本号或下载地址。

## 开发

版本唯一来源是根目录 `VERSION.json`。构建与测试见根目录 README。
