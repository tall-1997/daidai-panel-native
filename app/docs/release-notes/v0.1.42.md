# v0.1.42 中文更新说明

## 定时任务按钮

- 顶部搜索框及内部清除按钮统一为 Liquid Glass 表面。
- 批量、排序、状态筛选和分组筛选按钮统一为低透明折射材质。
- 导入导出、清除筛选、任务卡右侧菜单和分组菜单入口统一为玻璃图标按钮。
- 排序提示和底部导航上方批量操作区域统一为同套玻璃材质。
- 任务运行、停止、删除等操作继续保留 Emerald、Red 等语义前景色。

## 全应用按钮

- 降低 FilledButton、OutlinedButton、TextButton 和 IconButton 的浅色背景不透明度。
- 全局按钮边框改为与底部导航一致的低对比高光描边。
- 搜索框内部图标按钮使用透明背景，避免 Lens 内出现白色圆形实底。
- 深色模式继续使用蓝灰玻璃材质和高对比浅色文字。

## 行为兼容

- 保留所有按钮文字、图标、点击区域、尺寸和原有功能。
- 保留任务业务逻辑、Cron 表达式、任务列表、页面结构和底部导航。

## 下载说明

- Android：下载本 Release 中的 APK 文件安装。
- iOS：下载本 Release 中的 IPA 文件，通过 AltStore、Sideloadly 等方式安装。
