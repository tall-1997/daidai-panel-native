# v0.1.41 中文更新说明

## 风格统一

- Dialog、BottomSheet 和 PopupMenu 统一使用半透明玻璃材质、边框和圆角。
- “关于”仓库信息、Cron 解析预览、脚本上传清单和 SSH 公钥区域使用共享 Liquid Glass 表面。
- 应用锁图案点位迁移到 Liquid Glass 交互表面，选中状态继续使用主题强调色。
- 状态徽标、图表、日志终端和代码编辑器保留功能性配色与性能策略。

## 任务日志文件

- 任务展开菜单中的“日志文件”展示文件名、文件大小和创建时间。
- 客户端按完整文件路径关联任务日志记录，支持超过 100 条历史记录的分页匹配。
- 具有对应日志记录的文件可点击进入现有日志详情页。
- 孤立日志文件保留展示，并明确标记“无对应日志记录”。

## 页面导航

- 更多页进入二级页面时使用无过渡 root 页面，消除两套全屏玻璃背景交叉动画。
- 二级页面始终先绘制主题背景底色，再加载用户背景图片。
- 静态背景在首帧同步建立 Liquid Glass 捕获快照，修复页面进入瞬间的透明帧和闪烁。

## 下载说明

- Android：下载本 Release 中的 APK 文件安装。
- iOS：下载本 Release 中的 IPA 文件，通过 AltStore、Sideloadly 等方式安装。
