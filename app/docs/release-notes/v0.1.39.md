# v0.1.39 中文更新说明

## 任务页面

- 移除任务展开卡片中的“禁用 / 更多 / 删除”模糊侧滑按钮。
- 删除无效的侧滑手势、位移动画、返回拦截和操作面板状态。
- 任务卡恢复为单一 Lens，点击查看日志、长按选择，运行/停止按钮继续保留。

## 环境变量页面

- 每张变量卡增加 12px 独立底部间距。
- 增加 16px 圆角裁剪，限制 Lens 和文字绘制边界。
- 变量值最多显示 6 行，备注最多显示 2 行，超出内容使用省略号。
- 增加卡片底部内边距和备注间距，修复卡片紧贴与视觉重叠。

## 验证

- Android Release APK 构建通过。
- iOS Release IPA 构建通过。
- `liquid_glass_easy 3.3.1` Shader 资产编译通过。
