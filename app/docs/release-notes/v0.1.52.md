# v0.1.52 稳定性与冗余清理

## 稳定性修复

- SSE 使用连接 generation 隔离新旧连接，避免旧连接关闭新连接。
- SSE 非 2xx 响应直接报错，临时网络异常自动延迟重连。
- Token 刷新增 Auth epoch 与服务器校验，避免登出或切服后旧会话复活。
- 更新下载增加全局互斥，安装器成功启动后再报告完成。
- Android 安装前验证 APK包名和 versionCode。
- 任务视图加载失败不再阻断核心任务列表。
- 分页加载失败回滚页码，避免跳过中间数据。
- 登录后恢复通知点击或外部深链目标。

## 页面状态修复

- Android Runtime 使用 UTF-8 流解码和完整 SSE 行解析，页面销毁后取消监听。
- config.sh 编辑器支持脏状态、错误重试、保存反馈和刷新确认。
- 环境高级工具增加 busy、错误反馈和操作后列表刷新。
- 任务视图增加真实 Loading/Error、隐藏开关、JSON校验和删除确认。
- 权限路由与后端 viewer/operator/admin 角色契约对齐。

## 冗余清理

- 删除 14 个无引用主题 Provider 导入。
- 删除环境变量页面无引用旧启停、删除和确认方法。
- 删除未使用局部变量和面板设置冗余状态字段。
