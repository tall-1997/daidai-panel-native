# v0.1.44 中文更新说明

## Android 差分升级

- App 请求 GitHub 固定静态配置 `releases/latest/download/android-update.json`。
- 根据本地版本、versionCode 和旧 APK SHA-256 选择匹配的 bsdiff patch。
- 差分包下载后执行文件大小、MD5 和 SHA-256 校验。
- Android 原生层在后台线程调用 `bspatch` 合并当前安装 APK与 patch。
- 目标 APK再次执行文件大小、MD5 和 SHA-256 校验，通过后唤起系统安装器。
- 差分失败时自动回退完整 APK下载与安装。

## 兼容性与性能

- 已安装 APK信息读取兼容 Android 23–27 和 Android 28+。
- 日常运行仅增加更新检查时的小型 JSON请求，无常驻合并任务或 native 内存占用。
- 更新期间的 CPU、磁盘和网络开销均限制在差分下载与后台合并阶段。

## 发布验证

- CI 自动执行 `bsdiff -> bspatch -> cmp`，确认 patch 可逐字节重建目标 APK。
- Release 同时提供完整 APK、差分 patch、`android-update.json` 和 iOS IPA。

## 下载说明

- Android：通过 App 内更新或下载本 Release 的 APK安装。
- iOS：下载 IPA，通过 AltStore、Sideloadly 等方式安装。
