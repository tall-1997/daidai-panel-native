# v0.1.56 Android 普通版本地面板 MVP

- App 启动时自动发现并启动 `127.0.0.1:5700` 本地面板，端口冲突时使用动态回环端口。
- 新增 Android 前台宿主 Service，为持续调度和长时间依赖操作提供生命周期基础。
- 新增本地 SQLite 数据库、管理员初始化、PBKDF2 密码保护、登录 Token 和刷新会话。
- 新增本地主页系统信息与任务统计接口。
- 新增任务 CRUD、启停、运行状态、批量操作、Cron 辅助、日志和统计兼容接口。
- 新增环境变量 CRUD、分组、排序、启停和批量操作接口。
- 新增依赖列表、状态、取消、重装、批量操作、镜像和 Python runtime 兼容接口。
- 依赖运行时尚未安装时返回 `runtime_unavailable`，避免将失败误报为安装成功。
- 依赖日志增加连接恢复状态、明确终态和最近 1000 条内存上限。
- Python 与 Node 实际执行将在后续运行时组件阶段接入。
