# v0.1.40 中文更新说明

## 稳定性与认证

- 恢复严格 HTTP 错误语义，统一普通 API 与 SSE 的 Token 刷新协调。
- 保存轮换后的 Refresh Token，限制 SSE 认证重试并在网络中断后自动重连。
- 认证存储和服务器切换失败时回滚旧状态，避免部分写入。
- 应用锁初始化期间阻止业务页面交互，并保留用户的生物识别锁配置。
- 修复多个列表请求竞态、异步页面生命周期和周期轮询重叠问题。

## 列表与数据兼容

- 为订阅、依赖、登录日志、审计日志和 Open API 调用日志增加分页加载。
- 修复任务筛选后的批量选择、排序和分组编辑边界。
- 兼容订阅布尔字段的 bool、0/1 和字符串格式。
- 兼容 Dashboard 数字字符串和宽松 Map 响应，避免趋势图类型异常。

## 界面与性能

- 恢复任务单项操作菜单，保留启停、置顶、复制、统计、日志、编辑和删除入口。
- 环境变量顶部操作区适配窄屏，分组筛选长文本自动省略。
- 环境变量新建与编辑弹层支持键盘安全滚动。
- 修复主页面 Skia/Web Liquid Glass 捕获上下文，降低全屏捕获成本。
- 减少环境变量卡片内部嵌套 Lens，提高长列表滚动性能。

## 质量保障

- 增加分页、订阅字段和 Dashboard 数值解析回归测试。
- GitHub Actions 在 Android 和 iOS 构建前执行 `flutter analyze` 与 `flutter test`。

## 下载说明

- Android：下载本 Release 中的 APK 文件安装。
- iOS：下载本 Release 中的 IPA 文件，通过 AltStore、Sideloadly 等方式安装。
