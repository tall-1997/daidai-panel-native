# v0.1.43 中文更新说明

## Android 差分升级

- App 优先请求 GitHub Release 中固定地址的 `android-update.json`。
- 检测新版本后，根据本地版本和已安装 APK SHA-256 精确选择差分包。
- 差分包下载完成后校验文件大小、MD5 和 SHA-256。
- 通过 MethodChannel 在 Android 后台线程调用原生 `bspatch`。
- 合并后的 APK再次校验文件大小、MD5 和 SHA-256，随后唤起系统安装器。
- 基线不匹配、下载失败、校验失败或合并失败时自动回退完整 APK更新。

## 发布流水线

- GitHub Actions 从上一稳定 Release 下载 Android APK并生成 BSDIFF40 补丁。
- CI 使用 `bspatch` 反向重建目标 APK并逐字节比较，验证补丁有效性。
- Release 同时发布完整 APK、差分 patch 和静态 JSON配置。
- Android `versionCode` 设置为 43，确保系统安装器识别为升级版本。

## 性能影响

- 日常运行仅增加一次小型静态 JSON请求，无常驻 native 内存和后台合并任务。
- CPU 与磁盘开销只发生在用户执行更新期间，合并运行在 Android IO线程。
- 当前完整 APK约 67 MB，临时磁盘主要由 patch、下载临时文件和新 APK组成。
- 差分收益不足时流水线停止发布 patch，客户端使用完整 APK。

## 下载说明

- Android：下载本 Release 中的 APK 文件安装，也可在 App 内执行差分更新。
- iOS：下载本 Release 中的 IPA 文件，通过 AltStore、Sideloadly 等方式安装。
